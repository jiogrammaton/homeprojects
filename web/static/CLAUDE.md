# web/static/ — the browser client

Served at `/static/<name>` by whitenoise straight from this folder (no collectstatic). No build step, no framework.

| file | purpose |
|---|---|
| `app.js` | The entire client (~4000 lines, one classic script). The header comment lists its sections in order; search for `/* ---- <name>` markers. |
| `style.css` | All styles (~2000 lines). The header lists its sections. Order matters: later sections refine earlier ones. |
| `favicon.svg` | The house logo. |

All three are loaded with `?v=N` (see `web/templates/CLAUDE.md`); bump N on every change.

# app.js

## Basics

Terse naming. Globals: `T` tasks; `ST` settings blob; `V` view (`home|board|cal|stats|settings`, from `<body data-view>`); `SV` settings tab; `cur` id being edited; `SEL` selected labels in the dialog; `LB`/`PJ` index-addressable label/project lists for the current render (inline handlers pass indices); `MODE` task|project; `HOME` per-room counts for the map; `MAP` the house map; `ROOMS`.
Constants: `S` statuses, `SL` their labels, `PR` priorities, `FREQ`, `PAL`, `PROJ_PAL`, `BUILTIN_ROOMS`, `ROOMS` (`[id, name, emoji, floor]`, rebuilt from the map), `ROOM_GUESS`, `LEVELS` (rank tiers), `PLAN_W`/`PLAN_H` (800×540), `GRID`, `MIN_ROOM`, `ROOM_ICONS`, `OUT_ICONS`.
Helpers: `$` (getElementById), `esc()` (**always** escape user text), `api()` (**use instead of `fetch`**: adds the CSRF header, optional `{timeout}`, sends you to `/login/` on 401, reloads on 403), `ask({title, message, ok, danger, info, icon})` → Promise<bool> (the branded `#cd` dialog).

Flow: `load()` → `ensureProjColors()` → `draw()` → `home()` / `board()` / `cal()` / `stats(L, q)` / `settings(L, q)` (→ `labelsUI(q)` / `projUI(L, q)` / `sched(L)` / `miscUI()`). `load()` skips redraws when nothing changed. `draw()` applies the filter box and the Board's URL filters to `T` before rendering.

Dates are local `YYYY-MM-DD` strings; the server uses `date.today()` (server machine clock).

## Data rules shared by every page

- **Project order** (`projs()`): priority, then `porder()` index in `ST.porder`, then A–Z (= the Settings › Projects order). Used by Board, Projects tab, everything.
- **Rooms:** user-defined. `rebuildRooms()` (in `load()` and after saving the map) builds `MAP` from `ST.map` (else `DEFAULT_MAP` from the `map-default` json_script) and `ROOMS` = `BUILTIN_ROOMS` (house, yard) + map rooms. `isRoom`, `roomInfo`, `roomOpts` (built-ins + one `<optgroup>` per floor) read `ROOMS`. `guessRoom(p)` matches a map room's name inside the project name first, then `ROOM_GUESS` regexes (only if that id exists). `roomFor(p)` = stored `ST.rooms[p]` (with `LEGACY_ROOMS`) else the guess; `taskRoom(t)` = the task's own room if valid, else its project's. New room ids: `'r' + base36` (≤ 20 chars). The server mirrors this (`web/rooms.py`).
- **Frequencies are labels.** A label with a repeat is a frequency: `freqOf(g)` = `ST.freqs[g]` → built-in `FREQ` → `parseFreq(name)` (same rules as `web/repeat.parse_freq`). Intervals are `{n, u}` (`ivOfTask`, `sameIv`, `ivDays`, `repeatName`, `freqName`). `freqOpts()`/`freqOptionsHTML()` = One-off + every frequency label (shared by Settings › Tasks `fsel`/`setFreq` and the import wizard). `withFreq(tags, g)` keeps one frequency label per task; `syncTaskIv(t)` sets interval/unit from it. The task form has **no Repeat field** (the user wants repeats set only through labels): picking a frequency chip (`togL`) swaps out any other; `formIv()` = the selected frequency label's interval, else `FORM_IV` (an edited task whose repeat matches no label keeps it). Settings › Labels rows have `↻ #fq-i [#fu-i]` → `setFreqOf(i)` (asks first if open tasks change; blank = plain label → tasks become one-off). Rename/delete carry `ST.freqs`. Calendar uses `addIv`. Cards show a `.rpt` badge only for a repeat with no frequency label.
- **Ranking:** `LEVELS` = `[key, name, color, range, mood]` for perfect/thriving/livable/neutral/slacking/neglected; `TIER_MAX = [0, 3, 6, 10, 20]`; `tierOf(n)`; `roomLevel(s)` = `tierOf(s.backlog)` (ToDo only). Must match `web/ranking.py`.
- **Filter box:** `filterQ()`/`filterable()`. Works on every page except Settings › Miscellaneous (grayed out). `/` focuses it, Esc clears it.

## Home (map)

- `home()` → `homePlan()` → `homePage()`. Floor tabs (`floorTabs`: a pill track like the top nav, `FLOOR_SVG`/`OUTSIDE_SVG` icons, green on the current floor, tier-tinted `.ftn` to-do count; `curFloor()`/`setFloor()`, remembered in localStorage `homeFloor`) and **Edit map** (`.mapedit`, ghost tool button; icon-only on phones) above the SVG plan (800×540): yard background on `MAP.ground`, a plain lot on other floors. The house footprint is filled with the hallway color, so gaps between rooms read as hallway.
- **Moods:** each room `<g class="room" data-room data-tier style="--rc">` gets `moodSVG(r, tier)` between its shape and its label. `MOODS[tier]` = `[glow, sparkles, motes, heat]` (see the ranking table in `web/CLAUDE.md`). `MOOD_DEF` gradients go in each Home plan's `<defs>`; effects are clipped to the room (per-render `clipPath` id `mc<N>`, `MOOD_N` reset per render) and seeded by room id (`seeded()`) so redraws don't reshuffle. CSS animations use `--d/--dl/--rise/--sx`; all stop under `prefers-reduced-motion`.
- **Side panel:** the **Whole house** card (`.hcard`) shows the overall rank: `tierOf(total)` of every room's ToDo count (house + yard + map rooms), with a `.hrank` pill; links to `/board/`. The **Legend** is a `<details class="legendbox">` with a chevron, collapsed by default everywhere (`LEGEND_OPEN` remembers a toggle while the page is open). The **Rooms** card: heading row `.rhead` with `select#rfilt` (`ROOM_FILTERS`: All rooms / With tasks / Slacking or worse (11+) / This floor, with counts from `roomFilterOpts()`, localStorage `homeRooms`; `setRoomFilter` re-renders only the list and calls `bindRooms(box)`), a tier bar (`.tierbar`, segments link to `/board/?rank=<tier>`), then every room in `ROOMS` (`.hrow`: swatch, name, floor, tier pill, count). On >1000px the side panel is sized by the map (`.hside { height: 0; min-height: 100% }`): the Rooms card is `flex: 1 1 0; min-height: 210px` and `.hlist` scrolls; an open legend shrinks and scrolls first. On laptops the plan's `max-height` keeps the whole Home on screen (style.css "Home fits a laptop").
- **Tooltips:** `#tip` is `position: fixed`; with a mouse or pen it follows the pointer on hover (never on touch) and shows on keyboard focus. Click opens `/board/?room=<id>`. On touch (`LAST_POINTER`, since Safari clicks lack `pointerType`) the first tap sets `TAPPED_ROOM` and shows `.tip.tap` beside the room (`placeTip()`); tapping it (`tipTap()`) or the room again opens the board. Tapping elsewhere or scrolling hides it. `bindRooms(root)` attaches listeners after each render.
- **Phones:** the plan is cropped to the house; held upright (`phoneUpright()`, from screen dims so the keyboard doesn't flip it) it draws a turned copy: `MAP` is swapped for `rotItem`-rotated items during `homePlan()` (`ROT`, `MAP_UP` = the real map; restored in `finally`); Outside uses `rotBox(outBounds(MAP_UP))`. `.plan.turned` shows room names again. A `resize` listener redraws when the layout key (`HOME_ROT`) changes. `--topbar-h` is measured by a ResizeObserver on `.topbar`.
- **Labels that fit:** `roomLabelSVG(r, sub, num)` stacks icon, word-wrapped name (`fitText` → `wrapWords`, measured with a canvas, 14→9px, ellipsis last) and the to-do line, dropping the icon and then the to-do line in small rooms. Shrunken sizes must use inline `style="font-size"` (a CSS class beats an SVG `font-size` attribute). Phones show `.rnum` (big count) instead of names unless the plan is turned. `TS` scales labels (1.6 on Outside).
- **Garden & stairs:** the ground floor's yard shows 3 plant clusters (`GARDEN`, `gardenSVG(fp)`), each at the first of its `spots` clear of the house (+18), the yard label and other clusters. Stairs (`kind: 'stairs'`, `floor`, `to`; `isStairs`) are drawn solid on `floor` and as a dashed outline on `to` ("Up/Down to <floor>", `stairsText`). Overlapping flights are grouped (`stairsLayerSVG`, `stairsGroups`, one `stairsGroupLabel` per group). Stairs are excluded from `ROOMS`, counts, `guessRoom`, name checks and server `all_rooms()`.
- **Room shapes:** rooms and blocked areas may carry `pts` (orthogonal outline corners on the grid); `x/y/w/h` always hold the box (`boxOf`). Helpers: `ptsOf`, `cleanPts`, `simplePts`, `pointIn`, `cellsOf` (exact `overlaps()` for shapes), `labelBox` (largest inner rectangle), `shapeSVG` (`<rect>`/`<polygon>`), `settleShape`. CSS rules for rooms use `:is(rect, polygon)`.
- **Blocked-off areas:** `kind: 'blocked'` (`isBlocked`; `isFeature` = stairs or blocked = "not a room"; use `!isFeature(r)` wherever you mean rooms). Drawn by `blockedSVG` with the `#hatch` pattern (`HATCH_DEF` in each map SVG's `<defs>`).
- **Outside tab:** floor id `outside` (`OUT`, `isOutside`). `withOutside(map)` adds it (plus Back/Front yard areas) to older maps; `load()` saves it once. Canvas `outBounds(map, head)` = `OUT_W`×`OUT_H` (1400×940) centred on `houseOutline()` (coordinates can be negative), widened by `ST.map.lot` (`lotOf`, `LOT_STEP` 100, `LOT_MAX` 2000) and always reaching `head` above the highest item (`OUT_HEAD` 200 in the editor, `HOME_HEAD` 30 on Home). The house is drawn by `houseBlockSVG` (hatched; an obstacle: `hitsHouse`). Items: areas (dashed `.area`), structures (`kind: 'structure'`, hold tasks), trees (`kind: 'tree'`, `treeSVG`). `yardLabelSpot()` places "Yard & exterior · N to do". `coexist(a, b)` = pairs allowed to overlap.
- **One set of outer walls:** `houseOutline(map)` = footprint of `map.ground` (else the whole map); every floor draws those walls. Rooms on other floors are clamped inside (`roomBounds`); `fitToOutline(map)` trims/slides items (in `rebuildRooms()` for display and `edSave()` for persisting). Walls use `--wall`/`--wall-in` (slate, not black).
- Gotcha: don't put `pointer-events: none` on map item classes (a stale `.plan .stairs` rule once made stairs unclickable). The decorative `.mood` layer is the exception.

## Map editor

`openEditor()`, `ED = {map, floor, sel, drag, dirty}`: edits a deep copy; `renderEditor()` builds the page once, `edDrawSvg()` redraws only the SVG's children (so pointer capture on `#edsvg` survives a drag). Pointer events (mouse/touch/pen; `.edplan { touch-action: none }`): drag a body to move, 8 `.handle`s (`data-h` nw…w) to resize, snapped to `GRID` 10, min `MIN_ROOM` 40. Shaped items get `shapeHandles` (`v:k` corner, `e:i` wall, `s:i` ⊕ split); `edReshape` only accepts valid outlines. Keyboard: Tab to an item, arrows move, Shift+arrows resize, Enter selects, Delete removes, R rotates stairs (`edRotate`). Rooms give way: `edPush(r, before)` trims covered rooms from the drag-start snapshot (`edSnapshot`); a room that would drop below `MIN_ROOM` stays with a red outline and save asks about overlaps. New items use `edPlace(sizes)` → `edFreeSpot`. A plain click on a selected stairs flight cycles to the next flight under the pointer. The editor freezes the viewBox during a drag (`ED.drag.view`). Side panel: floor name, add room/stairs/blocked/structure/tree, name (unique), icon grid (`ROOM_ICONS`/`OUT_ICONS`; Unicode has no washing machine, so 🫧/🧼 stand in), delete (warns with `roomUse` counts), yard rename on Outside, Yard size −/+ (`edLotHTML`, `edLot`). `edSave()` writes `ST.map`, drops `ST.rooms` entries pointing at deleted rooms, then `rebuildRooms()` + `saveST()`. Cancel and beforeunload warn about unsaved changes.

## Board

- One `.pj` panel per project (`data-p`), with 3 `.col` drop zones (`data-st`, `data-s` label, `data-i` icon). Cards sorted by priority then due date; due colors from `dueWarn()` (`ST.dueYellow`/`dueOrange`, red ≤ 0 days). FLIP animation (`snapshot`/`flip`); `moveTask` sets `FLIP_ONLY` = the card's project so only it animates; `pjHeight`/`resizePj` animate panel heights.
- **Header:** `button.pjt` = chevron + `.pname` (`.pn` name + `.pprio`) + `.pstats` (open · done), then `.pact` with `.pbtn` ghost buttons (`PLUS_SVG` + Task; `.pbtn.del` with `TRASH_SVG`, red on hover). On ≤600px it's three lines (name + priority / counts / buttons). Hover styles are inside `@media (hover: hover)` so iOS doesn't treat the first tap as a hover.
- **Collapsing:** `togglePj(i)`; collapsed = `.pj.shut`. A click/tap on any empty part of a panel (not a card/button/link) also toggles it (document click listener). Defaults (`pjDefaults`, unfiltered board only), decided once per tab session: the first `OPEN_FIRST` (2) projects in `projs()` order with open tasks are open, every other project shut (sessionStorage `boardOpen2`/`boardFirst`, with the user's toggles). Filtered boards start all open (`PJ_OPEN_F`). `addTask` and a successful new-task save open that project. Lanes never scroll inside (the user removed that: it blocked dragging to other columns on phones).
- **URL filters:** `?room=` (`roomQ()`), `?project=` (`PROJECT_PARAM`), `?label=` (`LABEL_PARAM`), `?rank=<tier>` (`RANK_PARAM`: tasks whose room has that rank in `roomStats(T)`), each with a `.roombar` explaining it; `?status=` (`STATUS_Q`, set by clicking a `.head` column heading `button.hd`, kept in the URL by `setStatusQ`): one `.lane.one` column whose cards flow in a grid; the other two `.col.alt` columns are hidden but open while a card is held. `STATUS_SEEN` keeps a project visible after its last card moves out.
- **Card drag (one system for mouse, pen, and touch):** cards aren't HTML5-draggable. Mouse/pen: `pointerdown` (preventDefault; the click still opens the task) → moving > 4 px or holding `HOLD_MS` (180 ms) → `mouseLift()` builds a `TD` with `mouse: true` and reuses the touch path. Touch: hold `HOLD_MS` on a `.card` (or `.plist .prow`), then a `.touch-ghost` clone follows the finger; moving before the hold ends cancels, so it scrolls normally. `touchMoveTo` finds the target with `elementFromPoint`: a `.col`, or the held project's trash (`[data-drop="del"]`); over + Task it adds `.pbtn.deny` and `.touch-ghost.nodrop` (a drop there does nothing). `touchDrop` → `moveTask(id, s, ghost)`, or `flyTo(ghost, id)` back home, or `dropDelete(id)` for the trash (`ask` → `DELETE /api/tasks/<id>/del`). Esc while carrying sends it back. The page auto-scrolls near the edges; `TD_CLICK_BLOCK` swallows the click after a drop; `touchstart` sets `draggable=false` so iOS doesn't start a native drag. The ghost drops `.enter`/`.landed`/`.completing`/`.moved` (`.card.enter`'s animation would pin it to the corner).
- **Holding a card:** `holdOn(el)` adds `.holding` to its `.pj`: every column shows its `data-i data-s` pill tinted by `--hc`, + Task is grayed out, and the trash widens to "🗑 Delete" with a dashed red border (solid when `.over`). `touchBegin` clears `TD.target` after the columns open, so releasing without moving never drops.
- **Drop and landing:** `flyTo` animates the ghost to the card's new rect, then shows the card (`FLYING` → `.flying { visibility: hidden }`); `land(p, s)` → `markLanding()` adds `.landing` to the project and `.shine` to the column; `endLanding()` clears it after 2.6 s. `TD.keep` stops `touchCancel` collapsing the columns before the redraw.
- `delProj(i)` asks, then `DELETE /api/projects/del`.

## Forms (`#d`)

- **Opening:** `edit(id, proj)` fills the form; for new items `focusName()` focuses Title `#t` (or `#pn` in project mode) synchronously inside the click so phones open the keyboard. On touch/narrow screens `dialog#d` is pinned to the visible part of the screen (`--vvt`/`--vvh` from `visualViewport`), and `keepInView(el)` scrolls the focused field (with its label) clear of the top and the sticky buttons.
- **Saving:** `sv()` is single-flight (`SAVING`, `formBusy()` shows "Saving…"), blurs the field (closes the phone keyboard), and calls `svTask`/`svProject` with a 15 s timeout (`cantReach()` on abort). New tasks carry `save_key` (`SAVE_KEY`, new per form open and after each success; kept on failure). 409 → `dupNotice()`; `svProject()` blocks duplicate project names case-insensitively and rolls `ST` back if its PUT fails. `rm()` deletes the edited task.
- **Quick entry:** `#addmore` "Save & add another" → `saveAndNew()` → `readyForNext()`: clears title/URL/notes (or the project name), re-randomizes the project colour, shows `#qa-msg`, focuses Title, sets `QUICK` (Tab on `#t`/`#pn` then jumps to `#addmore`). New items start from `lastChoices('task'|'project')` in sessionStorage. `randomProjColor()` picks an unused `PROJ_PAL` colour.
- **Keyboard:** every form works with Tab alone. Inside an open dialog (`topDialog()`), Tab/Shift+Tab wrap and Enter in a one-line input moves to the next field. Label chips (`#lb`) are one Tab stop (arrows move, Space/Enter toggles: `lbKey`, `lbFocus`). Due date `#u`: Enter/Space/↓ opens the themed picker `#dp` (`dueKey`, `dpKey`, `dpFocus`; arrows by day/week, PageUp/PageDown by month, Esc closes only the picker). In inline-edit inputs, the Enter handler must call `event.preventDefault()` before `blur()`, or the keypress "clicks" the OK of any notice `onchange` opens.

## Settings, Calendar, Stats, Import

- **Settings tabs** (left to right): Projects, Tasks (key `tasks`), Labels, Miscellaneous. Projects and Labels show `taskCountLink(n, href)` → `projectLink(p)` / `labelLink(g)`.
- **Projects tab:** names are `input.lname.prname` (Enter/blur → `renP(i, value)` → `/api/projects/rename`, Esc restores; focus sets `draggable=false` so text can be selected). Four `.pzone` drop zones (one per priority); rows drag with HTML5 DnD (mouse) or the touch path; `pzOver`/`pzMark` show `.ins-before`/`.ins-end`; `moveProj(p, n, before)` rewrites `ST.porder` and priority, redraws with FLIP, then saves.
- **Labels tab:** `.prow.lrow` rows (swatch · name · ↻ repeat · N tasks · ✕/lock); `FREQ` built-ins have locked names but editable repeats.
- **Tasks tab:** `.tasktable` (cells with `data-label`, one card per task at ≤760px); priority, repeat and room per task (`fld`, `taskRoomOpts`).
- **Miscellaneous tab:** account (change password, sign out), `spawnDays`, due colors (`setNum` keeps orange ≤ yellow), clear old history (`oldHistory(days)` mirrors the server rule; `clearHistory()`), backup link, `restoreBackup()`, delete everything (`resetAll`).
- **Calendar** (`cal()`): 12 months ahead, grouped by season, read-only. **Stats** (`stats()`): follow the filter.
- **CSV import wizard** (`imp()` → `#iw`, state `IW`): step 1 summary tiles + "What's missing"; step 2 rows with live `rowProblems()`/`rowState()` (ok/warn/error/dup/skip), a "Needs attention / All rows" filter (`setShow` freezes the visible list), a bulk bar (`iwBulk`, `iwInclude`); step 3 result. Typing calls `iwSet` → `iwRefresh` (updates just that row). Esc or a backdrop click asks before discarding (`closeIW`).

# style.css

- Palette in `:root`: slate/navy surfaces (`--panel`, `--card`, `--deep`), light page `--bg`, green `--acc`, red `--danger`, map walls `--wall`/`--wall-in`. **No brown, no black walls.** Layout tokens `--pj-pad`, `--pj-stripe`, `--lane-gap`; runtime vars `--topbar-h`, `--vvt`, `--vvh` (set by app.js).
- **Touch:** `@media (pointer: coarse)`: 16px inputs (no iOS zoom), 40px minimum targets, no text selection on draggable things. `@media (hover: none)` removes hover lifts and adds `:active` feedback. `body { touch-action: manipulation }`.
- **Help icons** (`.help`): text from `::after` on hover/focus. In `#d` the tip hangs from the whole label and `#d` has `overflow-x: hidden` (a wide tip once made the form slide sideways on phones).
- **No horizontal page scroll:** no fixed min-widths; board columns `minmax(0, 1fr)`; lanes stack at 760px; Home stacks map + side panel at 1000px. Top bar breakpoints 1320 / 1120 / 960 / 600.
- Shared patterns: `.prow` (tinted row with a left color stripe) for Projects and Labels; `.mrow` for Miscellaneous; `.stats-card`; `.pbtn` ghost tool buttons; `.xbtn` red ✕; `a.btn`; `.roombar` (filter explanation bar).
- `.head` is inset by `--pj-pad`/`--pj-stripe` so column dividers line up with the lanes.
- Import wizard (`dialog.wiz`): state colors `--ok/--warn/--err/--dup` via `--wc`; rows `.wrow` stack under 860px.
- Home map: `.room :is(rect, polygon)` fill = `color-mix(var(--rc) …)`, `--rc` set inline from `LEVELS`; `data-tier="perfect"`/`"neglected"` rules strengthen the color; mood keyframes `lampGlow`, `twinkle`, `drift`, `simmer`, `rise`, `steam`, `edgePulse`.
